Agentic AI · PyTorch · LangGraph · MLOps

Industrial Agent Telemetry Engine

The Problem

Industrial equipment fails unexpectedly because traditional monitoring only flags problems after they've already happened. There's no system that connects fault detection to the fix automatically.

The Approach

Built an autonomous platform ingesting raw sensor telemetry, predicting cycles remaining with a dual-head PyTorch Bi-LSTM + Attention network, then routing alerts through a 3-agent LangGraph loop. Agents query Neo4j + Qdrant hybrid RAG to retrieve maintenance procedures and check a SQLite parts inventory — producing a structured work order with zero human intervention.

Causal ML · MLOps · Budget Optimisation

CausaLift-Engine — Causal AI Platform

The Problem

Standard ML tells you who will churn. That's not enough. If you contact a Sleeping Dog — a customer who churns specifically because you contacted them — you made things worse. Budget was being wasted on the wrong customers.

The Approach

Built a causal ML platform on the Criteo benchmark (2.5M rows) implementing S-Learner, T-Learner, and X-Learner meta-algorithms with IPTW to correct selection bias. Evaluated using Qini coefficient and AUUC — not standard AUC. Deployed as a 3-container Docker system with a CEO budget simulator and MLflow experiment registry.

Row Benchmark

6/6

The Result

A system that separates Persuadables (target these), Sleeping Dogs (never contact), Sure Things (save budget), and Lost Causes (skip entirely). Budget allocated exclusively to customers who actually respond to intervention.
